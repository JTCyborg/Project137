# Project137
АТМ Turbo 2+ — тест внешнего VGA-адаптера.

## Проверка стандартных видеорежимов

vga_test.asm проверяет запуск VGA software mode и чтение/запись VRAM, затем последовательно включает девять стандартных разрешений:

| Разрешение | Исторический стандарт |
|---|---|
| 320×200 | CGA / MCGA / VGA |
| 320×240 | QVGA / Mode X |
| 512×384 | Macintosh |
| 640×200 | CGA |
| 640×350 | EGA |
| 640×400 | PC-98 и рабочие станции |
| 640×480 | VGA |
| 800×600 | SVGA |
| 1024×768 | XGA |

Каждое разрешение проверяется в 8 bpp. Видеопамять заполняется проверенным шаблоном из Project132: используются шестнадцать индексов (0..15) предварительно инициализированной EGA-палитры адаптера. Это позволяет проверять адресацию VRAM и разрешения без обращения к неинициализированным записям DAC. Для каждого режима записывается только объём активного framebuffer; все режимы помещаются в 1 MiB VRAM.

После заполнения каждого режима программа ждёт нажатия и отпускания SPACE, поэтому изображение остаётся на экране до перехода к следующему разрешению. Отладочные сообщения выводятся на порт #EF (лог Unreal Speccy — spectrum_out.txt).

Первичная проверка 640×480 RGB565 с readback сохранена перед перебором режимов. После девяти разрешений выполняется отдельный тест 256-цветного DAC: записывается палитра RGB332 (256 уникальных индексов, 6 бит на компонент), framebuffer 320×200 заполняется индексами 0..255, затем все 768 компонентов палитры считываются обратно через 3C7h/3C9h и сравниваются с эталонной таблицей. Это проверяет именно программируемый DAC Project131, а не только начальные 16 EGA цветов.

## Сборка Windows

Запусти build.bat из Проводника или командной строки. Используется приложенный tools/sjasmplus.exe.

Результат:
- vga_test.TRD — загрузочная TR-DOS дискета;
- vga_test.lst — листинг ассемблера;
- vga_test.map — карта символов.

Перед сборкой старые TRD/listing/map удаляются. Если сборка завершилась ошибкой, не запускай предыдущий vga_test.TRD.

## Результат проверки на ATM Turbo 2+

Подтверждён запуск теста с 16 цветами EGA: индексы `00h..0Fh` отображаются корректно. Этот результат подтверждает работу текущего индексного 8-bpp шаблона, но не является проверкой полной 256-цветной палитры DAC.
